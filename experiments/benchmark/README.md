# Cross-backend benchmark

The benchmark will compare simulation, STM32N6, FPGA, Speck, and other neuromorphic backends through identical event windows and reflex outputs. Required metrics include prediction agreement, end-to-end p50/p95/p99 latency, sustained event rate, event loss, energy per window, false-stop rate, missed-risk rate, and recovery after overload. No cross-backend result is currently available.
