# Licensing status

The main project currently has no license. The repository owner must select one before claiming that the entire repository is open-source licensed; Apache-2.0 or MIT may be considered, but this document does not choose either.

Each third-party submodule remains governed by its own upstream terms. In particular, the AGPL-3.0 `dvs_tool` propagation and redistribution boundary needs separate legal review. A missing upstream license file is not permission to relicense that code.
